# iCodeForBananas for iTerm2

Two iTerm2 color schemes, dark and light.

## Install

Double-click either `.itermcolors` file, or import it manually:

**iTerm2 → Settings → Profiles → Colors → Color Presets… → Import…**

Then pick **iCodeForBananas Dark** or **iCodeForBananas Light** from the same Color Presets menu.

## Palette

| Role | Dark | Light |
|---|---|---|
| Background | `#0F1114` | `#FDFCFA` |
| Foreground | `#E6E8EB` | `#0A0C0E` |
| Cursor | `#FFCC00` | `#755000` |
| Cursor text | `#0F1114` | `#FDFCFA` |
| Selection | `#27456B` | `#BBD6F5` |
| Selected text | `#E6E8EB` | `#000000` |
| Cursor guide | `#1B1E23` | `#F1EEE6` |
| Link | `#A5D6FF` | `#0B5FD0` |
| Badge | `#FF8A82` | `#C21F2E` |
| Bold | `#FFFFFF` | `#3A2A00` |

### ANSI colors

| | Dark | Dark bright | Light | Light bright |
|---|---|---|---|---|
| Black | `#98A2B0` | `#B3BCC8` | `#16181C` | `#6E757E` |
| Red | `#FF8A82` | `#FFA198` | `#C21F2E` | `#E0132A` |
| Green | `#6FD28A` | `#7EE787` | `#157A34` | `#008736` |
| Yellow | `#E3B341` | `#F2CC60` | `#8A5A00` | `#A26800` |
| Blue | `#79B8FF` | `#A5D6FF` | `#0B5FD0` | `#006FF1` |
| Magenta | `#D2A8FF` | `#E2C5FF` | `#8A33C8` | `#A526F0` |
| Cyan | `#56D4DD` | `#76E3EA` | `#0D7478` | `#008288` |
| White | `#F2F6FA` | `#FFFFFF` | `#3F464E` | `#000000` |

Note that the light scheme inverts the usual black/white convention — ANSI black is near-black and ANSI bright white is `#000000`, so bright-white text stays readable on a light background.
